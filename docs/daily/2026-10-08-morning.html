研究前言｜把预算花在更多问题，还是反复问同一个问题

近七天，一个实际问题变得更突出：当快速判断和小任务越来越便宜，省下的预算应该花在哪里？检索评估的新论文把问题数、搜索路径和重复作答拆开，在相近模型用量下，覆盖更多问题比反复读取同一证据更能缩小比较误差。但这不是准确率提升，也没有证明自适应检索必然胜出。它给本期实践的启发是先划清工作单元，再定义验收：取到年报中的数字，要核对年份和单位；生成可点的界面，要测试边界输入；工具正常返回，也可能包含业务错误。论文是作者实验，产品效果多为官方或客户自述，尚不能当独立生产验证。结构化概率与漂亮界面都不能替代这一步。

    检索代理论文比较问题覆盖、搜索路径与重复作答；误差缩小不是答对更多，低温输出一致也不等于评估更可靠。

01Anthropic · Haiku 5.5 公告与 Rogo 客户原话 · 2026-10-07

大模型做演示稿，小代理只查年报中的那一行

十月七日的 Haiku 5.5 公告里，Rogo 团队给出一个具体分工：较大模型制作演示稿，轻量子代理到10-K年报里找所需的分部收入行。过去把查找和综合都交给同一种模型，现在把边界清楚、频次高的取数单独处理。这是厂商刊载的客户早期测试描述，没有公开该流程的独立准确率或端到端账单，不能写成已验证的财务自动化。

Rogo 面向机构，官网入口仍是预约演示；此配置的自助资格、大陆服务与合同价未公开，属于观察案例。Haiku API在输入不超过十万token时，每百万输入0.10美元、输出0.50美元，更长输入价格不同；这不是Rogo套餐价，人民币成本还取决于汇率与实际用量。Anthropic 官方支持地区不含中国大陆，不能把模型上线当国内可直接使用。

小团队可先用已有国内模型或本地模型借鉴分工：二十分钟准备一份公开中文年报，只问一个分部、一个年份，要求返回原文行、页码、单位，再人工对照PDF；核对后才交给另一个步骤写结论。普通电脑即可，模型收费按已有套餐或本地算力计。不要上传未公开财务资料；取对数字也不等于分析成立，投资或披露责任仍由人承担。

02OpenAI · GPT-6 与 Intelligent UI 发布说明 · 2026-10-07

回答变成可操作的小工具，先检查按钮背后的算式

OpenAI 十月七日开始在 ChatGPT 的 Chat 中推出 Intelligent UI：模型不只输出段落，也能组合表单、按钮、图表和小计算器，让读者直接改参数。官方用原生组件库和流式编译器逐步显示界面；这是回答形式的变化，不是每个生成工具都经过软件验收。此次发布不改变 Work 和 Codex 使用的模型。

先向Plus、Pro、Business、Enterprise逐步开放，公告称次日起扩到Free和Go；不代表每个账号今日已出现。官方更新记录还说明，Astra的Pro推理选项不支持该界面。已有合资格账号可在Chat提出“做一个按人数均分费用的计算器”，花十五分钟分别输入零人、一人、小数金额，手算交叉检查；应得到能解释计算规则、拒绝无效输入的小工具，而非只有好看的卡片。

中国大陆不在官方支持地区，本条对大陆读者属于观察应用，不能承诺开通或境外支付。现有订阅内按对应额度使用，免费档仍受推出进度和用量限制；不必为一次练习先买套餐。国内可用已有编程助手生成一个不联网的HTML均分器，在本机浏览器做同样测试，下载后无需境外账号或显卡；生成成本按所用服务计。这是替代练习而非同款功能，不输入真实账单、姓名和支付信息。

03Agentic RAG Evaluation · arXiv v1 正文与附录 · 2026-10-04

评估预算有限，别只让模型反复回答同一道题

十月四日首发的这篇v1预印本研究如何评估检索代理：同一笔预算，是覆盖更多问题、多走几条搜索路径，还是对证据反复作答？作者比较预先规划四次检索与根据反馈调整二至四次检索，固定最终读取五份文档；用DeepSeek V4.1 Flash与V4 Pro0813、HotpotQA和MuSiQue，避免把搜索路径变化与阅读随机性混在一起。

新增446个不同问题的实验中，三种分配消耗约3414万至3439万模型token。覆盖446题、每题两条路径且只读一次，相比174题读五次，比较结果的标准误下降约33%；相比298题三路径，下降12.6%。这是估计更精确，不是准确率涨33%。广覆盖方案的自适应检索增益置信区间仍跨零。另一个对照中，温度降到零让答案分歧变少，比较精度却几乎不变。

结果来自作者实验，局限于两类问答、一组模型和检索设置；更多问题也会增加搜索费，按token持平并非人民币账单相等，模型别名和索引未被不可变快照锁定。免费起步可用二十分钟核对正文三组预算与误差，并据此为自己的评测分开列问题数、路径数、读数。全文及附录给出提示和实验设置，但本次未找到可核验的独立代码下载入口。完整复现需检索基础设施、API预算与统计技能，不是普通电脑半小时能跑完。

agnostic-ai · v0.81.0 发布与共享记忆文档 · 2026-10-07

换一个编程助手，不必重讲一次项目习惯

agnostic-ai十月七日发布0.81.0，把不同编程助手的记忆统一成Markdown：团队事实进入可提交目录，个人偏好留在默认忽略的本地目录。过去切换工具要重讲约定，现在每次会话读取同一索引；团队事实须确认，个人偏好可自行保存，不能把记忆当高于用户指令的规则。

适合懂Git的小团队。由发布页进入Memory与Getting started文档，安装0.81.0以上版本后，在空白练习仓库初始化；配置builtins加入memory，先运行agnostic-ai sync --plan审查，再sync。二十分钟手写一条虚构项目事实，运行memory index与memory lint，检查索引链接和Git差异；应得到能审查的记忆文件，而不是不可见的聊天历史。安装下载另计，先不启用跨工作树的仓库级个人记忆模式。

MIT开源，本地整理无需模型账号或显卡，国内可下载官方二进制或用Node18+安装npm包，网络可能受限。真正让助手读取仍受各工具账号、地区与费用限制；本地存储不保证模型调用不外发。同步会写工具配置和启动钩子，必须审阅。不要存密钥或客户资料；能修改共享文件的人，也能改变助手下次读到的上下文。

DeerFlow · 独立扩展示例 PR 与 README · 2026-10-07

给代理补一张运行账：返回、抛错和取消分开记

北京时间今晨，DeerFlow合并一份独立扩展示例：同步和异步工具调用分别记录正常返回、抛异常、取消及耗时，任务结束时只汇总一次。它只改示例，不是主产品已经装好的监控面板。返回内容即使含错误，也算returned；并行调用耗时相加不等于总运行时间，重启后统计清零。

适合懂Python和虚拟环境的学生或开发者。由PR进入examples/deerflow-extension-example的README，在包含该提交的源码中按Run the package tests用Python3.12、uv建独立环境，先装本地extension-api，再装示例的.[dev]。准备好后花二十分钟运行uv run --no-project pytest -q，阅读tests/test_tool_stats.py中返回、异常、取消三类断言；应看到可核对的测试结果，维护者报告为二十项通过，本刊未复跑。

这项本地练习无需模型密钥、海外账号或显卡，除下载流量和设备外无API费用；国内源码和依赖下载仍可能不稳定。它不导入完整Gateway，不必接真实业务数据。进入生产流程还需接入、鉴权及持久化设计；扩展能执行代码，别把示例不加审查地装到生产环境。

Qwen Code · Web Shell 表格全屏 PR 与中文设计 · 2026-10-07

模型吐出的宽表，展开后不该丢掉筛选和阅读位置

Qwen Code十月七日合并会话宽表全屏查看：排序、筛选、列宽、选区及滚动位置应在展开和关闭后保留，Esc先关内层浮窗再退出。原来为看清模型生成的比较表要在窄消息栏反复拖动，现在可以保持核对上下文。它属于主分支源码更新，现有十月五日桌面0.25.0不能据此认定已包含。

适合懂React与浏览器测试的开发者。先从PR打开中文设计docs/design/web-shell-table-fullscreen.zh-CN.md；二十分钟把“筛选后展开、复制、退出恢复焦点”列成验收表，对照client/e2e/web-shell.table-fullscreen.spec.ts的80行10列模拟数据。已有源码依赖及Chromium时，可在packages/web-shell运行npm run test:e2e -- client/e2e/web-shell.table-fullscreen.spec.ts --project=chromium，检查对应断言；安装与构建另计。

阅读及模拟数据测试无需模型账号、API预算或显卡，国内入口是项目中文文档，GitHub与浏览器下载可能受网络限制。作者本地验证为macOS环境，未声称Windows、Linux均实测。普通用户先等正式版；无论显示多完整，都要回到原始表核对单位、缺失值和数字，别把真实客户清单放进练习。

OpenAI · Decisions 官方指南与价格限制 · 2026-10-06

判断接口可以更快，概率字段仍需自己校准

十月六日上线公开测试的Decisions，用专门端点让GPT-6 Luna对文字或图片给出条件概率、固定选项或分级评分。它不是生成任意JSON的替代品：分级结果是等级索引的概率加权平均，choice和score还另有confidence字段，不能混成同一个“正确概率”。依赖前一个答案的问题应分请求，独立问题才适合共用输入。

官方指南明确要求用业务标注样本设阈值。先准备二十个虚构客服问题，人工分出该转账单、技术或其他的类别，特别检查模糊与跨类样本；便宜的快速判断只适合在错误可被接住的环节试验。公开测试仅支持Luna，输入每百万token0.10美元，无输出收费，长上下文和区域处理另有乘数，不能套到其他Luna请求。

大陆不在OpenAI API支持地区；国内团队可先用已有国内模型或本地分类器做同样的标注对照，不把其输出当本接口同等校准。获准使用API者还需开发技能、账号及独立账单，人民币按实际用量与汇率计。高风险业务保留人工复核，不上传真实客户或敏感资料。
