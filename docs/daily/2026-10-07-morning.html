研究前言｜完成动作与达成目标之间，缺一层验收

近七天值得研究的问题，不是代理能点多少次鼠标，而是最后的状态是否满足原来的要求。合同流程中，表单建好不代表金额门槛真的生效；机器人夹爪合拢，也不代表物体仍在手里。新的研究把验收从动作序列里拆出来：先由懂业务的人定义失败条件，再检查最终状态，只有经过验证的经验才进入技能库。这里仍有证据等级之分：合同成绩是厂商研究自测，机器人结果来自作者实验，代码评审的人工复核也不是独立生产审计。本期应用据此关注三件可操作的事：让人留下明确反馈、检查模型实际读到的网页，以及追溯业务字段是谁改的。结构化输出只是起点，不是判断正确的证明。

01Answer me with HTML · v0.4.13 发布与中文文档 · 2026-10-07

解释页面能收回选择和评论，学习不再停在看完

昨天介绍的是阅读主题，今天发布的 v0.4.13 增加了实质不同的一步：读者可以在讲解页的 ask 问题中选答案，对面板写评论，再点“回复”汇总成文字，手动贴回助手。过去读完还得重新描述哪一段不懂，现在反馈带着原来的问题走。默认建议、改选和未回答会被区分；浏览器保存本地选择，但不会自动把它们发送给模型，也不是已经打通的教学管理系统。

适合会基础 Markdown 的学生、教师和开发者。由版本页进入仓库中文 README 和参考文档，下载该版本；已有 Node.js 20+ 时，先用 node skills/answer-me-with-html/scripts/am.mjs render examples/tcp.md 渲染示例。花二十分钟在一个面板内加一道 ask 选择题，改选一次、留一句疑问，点“回复”核对导出文字，再刷新检查选择是否保留。应得到一份可离线阅读、可带问题回到讨论的学习页；下载与环境准备另计。

MIT 开源，本地手写稿渲染无需模型账号、付费额度或独立显卡；国内下载 GitHub 可能不稳定，下载后不依赖国外模型。需要 AI 辅助时可用自己已有的国内模型，费用与数据条款另算。生成页会带入所引用的代码和素材，分享前检查隐私；默认建议不是正确答案，教师仍要核对知识与题目。旧页需重新渲染才能获得新功能，不必安装全局自动执行规则。

02OpenAI 与 Ironclad 研究合作公告及评估脚注 · 2026-10-06

合同代理开始按完整流程评分，而不是数点击次数

OpenAI 十月六日披露与 Ironclad 的研究合作：业务人员把采购审批、协议配置等工作拆成十一项任务，每项八至五十个验收条件，并提供软件练习环境。新方法针对的是跨步骤约束：金额超过门槛要找财务，特殊条款还要找法务；代理不能只建完表单便宣告成功。训练使用经个人信息过滤的公开合同合成任务，并非拿客户私有合同直接训练。

官方自测中，Astra Max 的平均规则评分为55.0%，Sol High为41.6%；这是部分条件得分，不是合同完整办结率。每次尝试19.2分钟与37分钟，是按假定处理速度计算的模拟时间，不是客户实测节省；演示中的高分也不能代替总体成绩。该公告仍是研究合作与未来产品方向，没有开放这套自动配置功能的试用价或大陆入口，属于企业观察案例。

国内小团队今天可以借鉴验收方法，而不是申请不存在的通用试用：用二十分钟在本地表格写一条虚构采购规则，列出低于、等于、高于门槛三个输入及预期审批人，再检查自己已有的审批流程是否吻合。无需境外账号或新增预算，不上传合同。真实落地仍要业务管理员、授权环境与专业复核；地区、支付和数据出境条件未在公告中说明，不能据此承诺国内直接可用，更不能让模型代替法律责任人签字。

03Skill2Real · arXiv v1 预印本及实验附录 · 2026-10-02

机器人把通过验收的技能带出仿真，抽屉仍是难关

Skill2Real 十月二日首发 v1，尚是预印本。它不重训一个通用动作模型，而在仿真中让提案者写操作程序、验证者诊断结果、准入者决定哪些经验可以保存；先学局部动作，再冻结它们学习长流程。转移到真机的是技能知识与统一接口，感知、标定和底层控制仍须为机器人实现，不能把“零样本迁移”理解成拿来就能换任意硬件。

作者用 UR5e、Pika 夹爪及顶部 D435、腕部 D405 深度相机，测试抓放、分类、算式拼放和抽屉操作，每种方法每类二十次。固定 Astra 与接口后，完整层级平均完成率78.75%，无技能27.50%，只有局部技能56.25%；抽屉仍仅10/20成功。仿真位置扰动也弱于对比方法 Zetta。桌布、灯光变化仅有定性录像，不构成各环境成功率；阶段增益还混入更多训练，不能全归因于层级设计。

论文链接进入项目页，可查程序与轨迹；无硬件者用二十分钟对照表一和抽屉视频，记录终态是否出现、是否省略等待，得到一张证据表。部分真机录像加速且删去规划等待，未报告完整延迟与安全接管统计。复现实验需仿真、模型调用、机器人标定和控制技能；完整训练有数千次仿真回合，算力与人民币总成本未披露，不是半小时真机复现。国内读者可先免费核查图表，实体执行必须由有资质的实验团队安排安全措施。

Cherry Studio · Crawl4AI 接入 PR 与测试 · 2026-10-07

把网页正文抓取放回本机，再交给桌面助手

Cherry Studio 今晨合并自托管 Crawl4AI 网页抓取：桌面助手可向自己的服务请求 Markdown，不必每次把网址交给外部抓取商。它处理已知网址，不是搜索引擎，也未接入云版或批量抓取。当前正式版仍是九月三十日的2.1.4，不能指望更新稳定版立即出现这个选项。

适合会 Node、pnpm 与 Docker 的开发者。由 PR 进入开发指南及自托管文档；先准备包含该提交的独立开发环境和至少4GB容器内存，安装时间另计。二十分钟练习：在网页搜索设置填本机11235端口及令牌，抓一页公开中文文档，比对原文标题、数字和表格是否保留；应看到可核对的正文，不能只看摘要。Crawl4AI 0.9起默认要求认证，服务端与客户端令牌须匹配，端口仅向本机开放。

不需国外抓取账号或独立显卡；本机抓取无按次服务费，但模型推理另计，可接国内可用服务。镜像和源码下载可能受网络限制。没有构建经验先等正式版；维护者尚未做真实自托管浏览器联调。只抓获准访问的公开页，不导入登录凭据；本机抓取后把正文交给云模型仍会外发，并非全程本地。

respond.io · 十月六日生命周期日志更新 · 2026-10-06

销售线索被谁推进，人与代理终于能分开查

respond.io 十月六日上线阶段变更日志，记录线索从哪一阶段到哪一阶段、何时发生，以及修改者是人、AI代理还是自动流程。过去只看漏斗变动，现在可以回到具体记录核查代理是否误把客户推进成交。新来源字段只从六日起有数据，批量导入和部分批量操作不记行；跨阶段跳转会展开多行，不能把行数当客户数。

这是面向海外业务的观察案例。已有账号及报表权限者可用二十分钟进入 Reports→Lifecycle，筛选某个AI代理、导出少量变更，再抽查对应会话；结果应是可追溯样本，不是因果归功。官方提供七天Growth试用，年付折算159美元/月，人民币按结算汇率另计；WhatsApp费用不包含，超额联系人与AI额度也可能加价。

大陆访问、境外卡与消息渠道资格需先确认，不能把这套工具当国内客户渠道通用入口。国内团队可在已有本地CRM里仿照记录前后状态、时间、操作者类型和复核人，用虚构线索先验流程，无需购买海外套餐。客户聊天、电话和名单不应未经授权外传；字段被改成“成交”，不等于款项真的到账，仍需业务核验。

GitHub · ReviewBench 方法、样本及研究预览 · 2026-10-05

代码评审测什么，先别把评论多当成更可靠

GitHub 十月五日推出 ReviewBench 研究预览：参考1.039亿个PR的分布，实际测试集只有219个PR、187个仓库、19种语言，并刻意增加有实质改动的样本。它把人工、模型与静态分析发现去重，再按统一规则判真假，区分漏掉多少问题与制造多少噪声。不是在一亿次评审中证明模型可靠。

资深工程师复核金标准的一致率为96.6%，但评分仍使用模型裁判，官方线上改进也是自身实验。新增发现会改变扩展召回率分母，跨系统应优先看固定金标准召回；榜单只发布首次或更好成绩，还需留意选择偏差。国内团队可先免费阅读公开案例，为自己的只读评审列出“严重漏检”和“无效评论”两栏；完整在线评测需要GitHub登录、容器与自备模型密钥，费用和访问另查，不能把私有源码直接送入公共评测。

Reflection · Beam 原始发布说明 · 2026-10-05

开放权重的承诺，还不是今天能部署的模型

Reflection 十月五日介绍 Beam，尝试用强化学习与长度惩罚改善编码、代理任务的推理效率。官方计算量比较不含提示预填充、注意力和服务开销，不能等同实测价格。现在仅向部分用户开放早期版本，权重、模型卡与技术报告计划本月稍后发布；大陆资格和价格未确认，不应写成可立即本地部署。先保留自己的任务与成本基线，等可下载版本和独立结果再比较。
