研究前言｜说完成、格式正确与真正完成之间

这几天，一个比“回答更聪明”更具体的问题浮现出来：怎样让模型的承诺对应可检查的结果？千问语音团队把工具训练放进可执行环境，先查数据库状态和写入权限，再评价回答；机器人研究则要求人的示教和机器执行遵守同一组运动约束。前者是团队自测，后者是受控真机实验，都不是普遍可靠性的证明。我更愿意把它们读成一种验收方法：不要只检查语言和格式，还要检查它改变了什么、是否越界，以及失败后能否退回。本期的文档精修、生图编辑和编程练习也沿用这个问题：保留原件，只改小处，用能够逐项核对的结果决定是否继续交给它。

01Step Code 官方中文说明与9月22日文档更新 · 2026-09-22

阶跃把写代码与交付静态页面接起来

阶跃在9月22日补充了Step Code的StepPage发布说明：终端里完成页面后，可以发布静态网址，并管理版本、回滚。它试图接上过去“让AI写完，再自己找地方部署”的最后一段；这是现有工具的新交付流程，不是今天才推出一个编程模型，也不代表任意后端应用都能一键上线。

国内入口是platform.stepfun.com；支持国内Step Plan登录或开放平台API Key，海外账户另设入口。有终端基础的学生或小团队，可按原文安装后，用20分钟在自有小项目副本里先选Read Only模式梳理结构，再切Ask模式让它从一个错误码文件生成docs/errors.md。完成后应得到代码、含义、触发条件逐项对应的表，再人工查漏项。Mac、Linux可用；Windows原生仍为beta，官方推荐WSL，安装时间不计入练习。

工具代码是MIT许可，不等于模型调用免费：已订阅者消耗套餐内用量，API按请求计费。本次未核实登录后的人民币单价，别仅为这个练习购买套餐；先查看报价并自设小额预算。代码会交给所选云端模型，移除密钥和客户资料。进入团队流程时保留差异审阅与测试，静态发布只用公开素材；没有核实的发布费用、访问控制与可用性承诺，不当作生产托管保证。

02腾讯云：Hy生图调用指南 · 2026-09-21

混元多轮改图先拿三张样片检验

9月22日对外发布的Hy Image 3.5 Preview，已提供文生图、参考图和多轮编辑的云端接口。链接文档在21日晚已更新，不把文档日期冒充发布日。对做活动物料的小团队，变化不是多一个聊天框，而是生成之后可把历史结果带回下一轮，继续改文案和画面；但预览版不保证每次保留同一商品、字体与布局。

会使用API的个人开发者，可从原文进入腾讯云TokenHub：注册账号、开通服务、获取Key，并在“在线推理—视觉模型”启用后付费。普通联网电脑即可，不用买显卡。准备一张自己拍的物品照片和虚构活动文案，开通后用20～30分钟按示例生成2K海报，再只改日期、只改背景各一次；把三张图并排，逐字核对日期、价格与物品外形。合格结果才进入设计稿，正文与价格仍由人定。

官方《模型价格》当前列出1K和2K折合0.15元／张，4K为0.20元／张：上述三张2K样片参考生成费0.45元，失败重试与其他云服务另看账单。下一轮应回传assembled_history，而非只复制图片链接；最终图地址默认12小时失效，要及时保存。国内云账号与后付费是门槛，不宣称有固定免费额度；不要上传客户证件、未授权人像或保密新品，云端编辑不是本地处理。

03PAKT 论文v1与实验附录 · 2026-09-22

教机器人之前，先让示范动作做得到

9月22日首发的PAKT v1预印本，针对一个朴素瓶颈：人拖着机械臂示范得太快，策略学到的动作未必做得到。作者保留示范加在线强化学习，把示教和策略输出放进同样的速度、加速度与加加速度约束，再交给控制器执行；改的是教学与执行接口，不是让机器人凭视频学会所有家务。

实验是真机Franka Emika机械臂及夹爪、两台腕部RealSense D405，另用Jetson与RTX 4090；四项插入装配任务都预先夹好物体。每任务每方法20次示范，最终100次测试；内存条任务做五个种子，其余单次训练。内存条成功率从基线88%到PAKT98%，但只换控制器的混合方案也到99%，表明提升不能全归给徒手示教。

策略10Hz、底层控制1kHz并非端到端延迟；人工按住接管开关暂停策略。论文没有证明最坏接触力安全，单名受训操作者、位置仅小范围随机化，也不证明跨家庭泛化。国内无硬件读者可免费用20分钟对照表3和附录的基线、混合方案、PAKT三列，区分控制与示教贡献。真机复现需要控制和强化学习技能及上述昂贵设备；两个工业任务还隐去部分几何细节，项目网站本次未读到，不能承诺代码齐全或半小时复现。

办公助手终于可以只改选中的一处

仍处Beta阶段的Kimi Work，9月22日3.2.12版加入PPT、Excel、Word与Markdown选区精确修改。过去一句“改得简洁些”可能牵动整份文档，现在可把修改对象收窄到段落或表格区域；这解决的是编辑范围，不保证数字和公式自动正确。

国内从kimi.com的电脑客户端下载，适合学生与办公室小团队；需Kimi账号、Windows 10以上或Apple芯片Mac，Mac要求macOS 12以上。安装更新后，用15分钟复制一页虚构报价单，只选说明段落要求缩短三分之一、不得改金额；再核对原件与结果的金额、表格和页数，得到可交给同事复核的版本。无需编程或独立显卡。

官方会员表入门自动续费月付49元，Work与其他会员功能共享按实际消耗计算的积分，不是无限次；先查账户资格与余额，别把下载免费当作任务免费。只授权练习目录，不交出整盘文件；本地客户端也会用云端推理，合同和客户信息需脱敏。进入正式流程仍保留原件与人工验收，复杂公式另用确定性计算检查。

Firecrawl团队9月22日发布Alexandria，把发现数据源、查看覆盖范围、查询资料接成一个入口。创始人回顾Mendable文档问答业务时，反复卡在清洗网页与逐个接供应商；现在尝试把这段重复工程产品化。研究索引主要是论文摘要，不能拿检索结果代替读全文；与Wikimedia Enterprise的数据合作已发生，面向作者自助付费分成仍是计划。

这是海外观察案例：服务已有API、MCP和CLI，但本次未确认中国大陆账号、支付与连接稳定性，不写成人人即开即用。官方通用免费档为每月1000积分、免绑卡；不同接口扣费不同，付费Hobby月付19美元，人民币结算随汇率及税费变化，专有数据费用另核对。需要联网电脑、服务账户和API使用基础，不能上传公司内部文档或人物资料做未经授权的丰富化查询。

国内可先不花钱复现方法：用20分钟选三个能直开的官方文档页，列出更新时间、适用版本、原文段落，再让已有助手据此回答同一问题。预期产物是一张可追溯证据表；找不到证据就留空。把它嵌进选型流程后，人工抽查链接与结论，不让漂亮摘要替团队做采购决定。

Qwen-Audio-3.1-Realtime技术报告v1 · 2026-09-21

语音助手要学会查结果，而不只是答应

千问语音新系列9月23日对外公布；这里读的是21日首发的3.1-Realtime v1技术预印本。它把文本教师蒸馏与可执行环境里的强化学习结合起来，让工具调用接受数据库状态、权限与中间步骤检查，而非只看说得像不像成功。

团队自测的半双工、语音输入文字输出版τ-Voice，任务成功率由3.0的78.4%到82.0%，表6未列总样本量；这不是官方全双工协议，不能直接横比其榜单。后台语音响应减少也不代表总延迟更低：论文同时报告轮次切换变慢、部分指标回退。长程真实录音任务仍缺充分检验；持续任务原型用的是3.0前台，不能挪作3.1的上线成绩。

国内学生无需账号、GPU或付费，可从原文第4节和表6开始，用20分钟画出“请求—工具—数据库—确认”四步图，列一个口头声称成功但状态未改的反例。它能成为语音应用验收用例，不是复现训练。完整复现还需要音频数据、强化学习环境与训练算力，论文未给出可直接照搬的个人成本预算；真实写操作仍应由系统权限和确认机制约束。
