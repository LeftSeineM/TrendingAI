今天真正重要的三件事

01OpenAI：ChatGPT Release Notes · 2026-09-17

ChatGPT进了Word：改稿更顺手，事实仍要自己把关

OpenAI在9月17日的更新说明中宣布，ChatGPT已作为Microsoft Word加载项提供。它能从笔记起草、概括现有文档、修改选中的段落，也能调整标题和格式；免费计划也在支持范围内，但仍受相应使用额度约束。过去写材料常要在网页聊天框和文档之间来回复制，现在编辑可以留在原稿旁边，逐段看它改了什么。

如果你的Word和ChatGPT账号都能正常使用，先从Microsoft Marketplace安装加载项，拿一页不涉密的旧稿做15分钟对照：只选中一个啰嗦段落，让它压缩到原长度的一半，再核对数字、出处和语气。中国大陆的ChatGPT服务、应用商店和账号条件可能限制直接试用；不要假设所有读者今天都能装上。国内可用的文档AI也可按同一办法比较，尤其要看改完后是否保留原意。合同、病历和客户材料不宜直接上传外部服务。

02Qwen Code v0.24.0 官方发布记录 · 2026-09-16

Qwen Code更新了长任务的“看得见”部分，适合从小仓库试起

通义团队9月16日晚发布Qwen Code v0.24.0。更新重点不是又换一个更会聊天的模型，而是让后台任务在daemon和网页终端之间可追踪、让命令钩子显示进度，并给一次会话的网页搜索设上限。做较长的编程任务时，最容易丢的是“它运行到哪一步、改了哪些文件”；这些变化是在补工作过程的可见性。发布记录列的是软件功能，不保证每个项目都能自动修好。

有编程基础的读者可从官方仓库的Quickstart进入，准备一个已提交到Git、没有密钥的小项目和可用的模型服务账号；中国大陆可选阿里云百炼北京地域，额度与API费用先看控制台。今天只给它一个20分钟任务：解释一个测试失败的原因、提出最小修复，并在执行前让你确认；结束后看diff、跑原测试，再决定是否保留。不要一上来授权它改生产配置或自动推送。

03华为：Peerium计算架构公告 · 2026-09-17

华为把更多芯片连成一台“大电脑”，但新架构还在工程验证

华为9月17日公布Peerium计算架构，核心想法是用统一互联把处理器、内存、存储和网络组成规模更大的计算系统。官方材料把状态分得很清楚：基于Atlas 950的25.6万卡集群正在部署，采用近封装光技术的Atlas 960系统仍在测试。发布的是架构路线与工程进度，不是普通团队今天就能租用的新实例，也不能据此断言所有模型训练成本已经下降。

对国内开发者，真正需要观察的是CANN、PyTorch适配、云上实例和迁移工具能否让现有代码稳定跑起来。若你正在选国产算力，可先用同一个开源推理任务对照兼容性、耗时、显存和运维成本；没有实际服务报价前，别把大会公布的系统规模换算成自己的预算。

百度智能云：端到端语音模型Flex公测公告 · 2026-09-16

百度让语音助手可以调用工具：先做一件只读小事

百度智能云公布的Flex公测版把实时语音理解、合成与Function Call接起来：开发者可将语音请求转成对外部工具的调用。相较只回答“天气怎样”，它瞄准的是“帮我查日程并反馈结果”这一类可验证的流程。公告同时说明知识检索RAG还要以后上线，所以不能把未来能力写成现在已经具备。

适合会用API和WebSocket的国内开发者：从公告中的接口文档出发，准备百度云账号、麦克风和一个只读的测试函数，用20分钟做“说出城市—查询公开天气—读回城市与结果”。先对照调用日志检查城市、参数和失败时的回复，成功后才考虑写入日历或下单。公测资格、调用费用和额度按控制台实际显示；不要让语音误识别直接触发付款、删除或敏感业务操作。

微软Power Platform九月功能更新 · 2026-09-17

微软的应用生成器先出方案再动手，企业要验的是权限

微软9月17日的Power Platform更新说明，model-driven app-builder skill现已正式可用。团队可以先用自然语言描述业务流程，由工具生成用户角色、数据表、表单、视图与权限等建造计划；有人批准后，才开始创建标准Power Apps和Dataverse组件。关键变化不在“一句话造应用”，而在生成前有一份能审的计划，生成后仍能回到人工设计器继续改。

这主要适合本来就使用Power Apps、Dataverse和相应企业租户的团队。可借鉴的起步办法是先用假数据设计一个请假或报修流程，把申请人、审批人、可见字段和异常路径写清，再让AI生成计划并逐项审阅；不要直接接生产客户表。中国大陆租户的功能可用性、许可和数据区域需由管理员核实，本文不把全球GA等同于国内全量开放。

Google Shopping：AI购物更新 · 2026-09-16

Google让商品问答走进广告，国内卖家先补齐自己的商品资料

Google宣布面向美国合资格零售商测试YouTube广告中的Business Agent，让观众不离开视频就能询问产品；Merchant Center也扩展了对话式商品属性和购物结账集成。Tapestry等品牌已接入部分流程，但结账扩展正逐步在美国推出，澳大利亚和加拿大还要等到明年。这是商家怎样把AI放进购买前答疑的观察案例，不是中国商家今天新增的投放渠道。

国内卖家能借鉴的是资料准备：取一件自己的产品，列出尺寸、适配、库存更新方式、保修和三种不能承诺的情况；用现有客服工具生成十组问答，再逐条核对商品页。若答案需要实时价格或库存，就必须连接可信数据源；AI编出的折扣与售后承诺不能直接发布。投入广告预算前，先看这些基础资料是否准确。

Anthropic：Life Sciences Verification Program · 2026-09-17

生物研究模型放宽限制，代价是资质审核与持续留痕

Anthropic推出生命科学核验计划的测试版。通过研究资质、安保和伦理审查的团队，可申请比普通产品更宽的生物研究使用权限；风险较高的项目另需逐项审批。计划目前面向团队和机构，个人Pro、Max用户尚未开放。它并非宣布AI已经替代药物研发，而是在“科研问题被安全过滤误拦”与“双重用途风险”之间重画使用边界。

这条新闻对研究团队的实际意义在于审批、数据和责任：Anthropic称会按申请用途监测异常行为，并为此保留相关流量30天；带患者身份信息的项目还受额外合规限制。中国研究机构是否符合申请资格、跨境数据如何处理，都不能从这篇公告直接推定。普通读者今天不需要尝试绕过防护，更该问：当模型参与高风险实验时，谁负责核验输入、记录每一步、制止越权？

Anthropic Institute：研发进度测量提案 · 2026-09-17

前沿实验室开始公布“AI参与造AI”的量尺

Anthropic提出三类公开指标：AI完成多少模型研发工作、代理操作能否被人监督、算力流向何处。其内部快照称Claude目前没有完全自主承担被测研发子任务，但在所定义的任务中“主导”26%。分类方法由公司制定，跨实验室尚不统一；公司表示计划邀请第三方核验。读者看到“AI设计下一代AI”之类标题时，先问测的是协作、主导还是完全自治，别把三个层次混成一件事。
