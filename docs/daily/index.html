“模型对自身推理的陈述，并不一定是其信念或行动理由的可靠证据。”

Codex 额度刷新消息置信度：未核实｜第三方记录转述十月十一日十二时零一分北京时间“重置已传播完成”，但原帖读取返回禁止访问，套餐、地区与到账范围未核实。两站引用同一原帖不算独立确认；另一预测站历史明显滞后，不引用其概率。以账户用量页为准。 核验：2026-10-11T14:07:05+08:00 · 官方用量说明 · 第三方重置记录，原帖未核实 · 被转述的原帖，本次无法读取

研究前言｜过程完成与任务完成之间，还隔着什么

这周值得追问的问题不是代理还能多跑几步，而是每一步留下什么证据。一个翻译任务显示结束，原文却可能漏掉整页；一个网页代理通过更多检查点，整项任务完成率仍可能较低；模型解释自己只是在演示，也可能已经提交真实表单。方法上的变化，是把验收从最终回答移到页码、工具调用、授权和可撤销的改动记录上。这里要分清证据层次：产品维护者的模拟回归测试、厂商自己的系统评测，以及内部事件调查，均不是独立生产审计。本期从阅读、排障和团队观测切入：先让遗漏与错误可见，再决定哪些数据、费用和写入权限能交给代理。

01EasyRead 正式版发布说明 · 2026-10-10

论文译完不等于没漏页，阅读工具开始逐页验收

中文论文阅读项目 EasyRead 十日发布一点四点一版，解决一个比翻译措辞更隐蔽的问题：两页一批时，模型只译一页，另一页也可能被记为完成。现在逐页查有正文却无对应译段的情况，单页重试后仍失败就提示补译；已有误标空页在升级后重新归入待译。跨页续写与错误页码有单独处理，不能把这项检查理解成全文事实校对。维护者公布的漏页验收使用假模型，真实模型测试只覆盖指定论文页，不代表所有论文。

学生和研究助理可先从 https://edwardxlai.github.io/easyread/demo/ 用普通浏览器免费读双语样稿，无需账号或显卡。二十分钟任务：选一个实验段落，把条件、基线和结果各抄成一行，对照英文与中文，标出一处不能仅凭译文下结论的地方。应得到三行证据表；这是阅读练习，固定样稿不能演示新版漏页重试。本次入口曾可直接读取，国内连接仍取决于网络。

真正翻译自己的文件需安装对应系统版本，再配置模型 API、已登录 CLI 或本地模型；安装、权重下载另计时间。软件入口不等于免费推理，国内供应商按各自人民币计费，公告没有统一每篇价格，先用公开两页材料看用量再扩大。文库在本机也不等于数据不出境：选中的文字、问题和页面图像可能送往所选服务。不要上传未公开稿件；引用和数字仍回原论文人工核对。

02Cherry Studio 正式发行说明 · 2026-10-10

桌面助手开始给自己看病，修复建议不能自动获准

Cherry Studio 十日正式发布二点一点五版，把诊断报告交给内置 Doctor 代理解释并提出有限修复。过去用户在模型、网络、插件和配置之间猜故障，现在可以先看检查结果，再决定是否咨询 AI。正式版源码说明区分本地快查、联网检查和需要确认的模型对话；修复绑定具体报告，过期或目标改变时应拒绝沿用，不能拿旧结论修改新配置。

适合已使用这款中文桌面助手的个人或小团队。来源页提供 Windows、macOS 和 Linux 安装包；下载、安装和备份另计时间。二十分钟练习：在系统诊断面板只做本地快速检查，选一项结果，记录状态、证据和建议动作，再检查建议究竟是跳转设置、重启还是改配置。应得到一张三列排障表；没有故障也记录通过条件，不人为破坏环境。此步骤无需模型账号、显卡或 API 费用，国内获取安装包取决于 GitHub 连通性。

AI 咨询另需可用模型与账户，按所选服务额度或人民币账单计费，不能给出统一咨询价。官方实现会读取限定范围的日志与应用状态并作脱敏，但仍可能把诊断信息交给模型，脱敏不是无泄漏保证。配置类提案须人点应用；撤销有状态条件，部分目录修复并不可撤销。练习不改代理、密钥或生产配置，也不启用渠道自动回覆；先审查报告再咨询，不能把助手说“修好了”当作实际连通验证。

03Pine AI 原始发布公告 · 2026-10-09

代理的云电脑进入私测，检查点多不等于交付完整

Pine 九日宣布开发者私测：产品通过 SDK 创建云电脑、交给它跨网站和文件的任务，再接收结果。网页被读取成结构和变化，用户仍可看屏幕、接管并交还控制。Pine 称自己的助手和企业业务已使用这一系统，并举出审计工作案例；客户未具名，效果没有独立审计，本刊不沿用其增产数字。它展示的真实工作关系是产品团队管理体验与授权，平台管理执行环境，不能把双方责任一并交给模型。

目前只能申请候补，不能把公告写成今天人人可用。中国大陆资格、支付、中文表现和数据驻留未核实，公开材料没有足以算人民币总成本的服务价；模型 token 成本不是云电脑总账单。应作为观察案例，不上传客户档案申请演示，更不要绕过地区限制。

公告自己区分检查点得分与整项任务完成，并承认系统间软件和预算不同，因此跑分不能单独证明架构优越。国内小团队可在已有助手或本地工具里借鉴这条流程：用虚构采购材料列需求、比较含运费总价、输出草案，在任何付款前停住让人确认。这是流程设计练习，不是同款复现；账号和费用沿用自己的工具，生产接入还要明确失败回传、会话隔离和人工暂停入口。

Confident AI 产品更新日志 · 2026-10-09

团队不用逐条翻日志，先把错误归到工具和参数

Confident AI 九日更新观测工作流：汇总哪些工具常失败、什么参数反复出现，并把单个子代理的调用分支从整棵执行树中取出。分类和数据入队还可触发后续工作流，人工标注与评估也更靠近同一条记录。它解决的是团队在长日志里逐条找错误，而不是保证 AI 裁判一定找对原因；新增验证数据图表恰恰提醒人要检查评分与人工意见是否一致。

国内小团队先把它当观察案例：大陆服务资格和支付可行性未核实，云端收集轨迹涉及代码、客户文本与数据出境。定价页免费档限两席、一项目、每周五次测试与一 GB 月跨度数据；工作流等能力在每月二百美元起的档位，不能承诺新增分析全免费，人民币按实际支付汇率另算，模型评估费用也要核对。

今天可花二十分钟把二十条虚构调用按工具、错误、参数缺失和重试次数分组，人工读三条高频错误，区分接口坏了与代理选错工具。应得到三项修复假设；本地表格无需账号和模型费用。这不是平台试用，而是上传真实轨迹前的验收设计。

TokenRouter，arXiv 第一版 · 2026-10-08

一段回答里换模型，真正瓶颈可能在调度而非推理

清华与卡内基梅隆研究者八日首发 TokenRouter 预印本。普通路由为整次请求选模型，它研究同一回答内部按 token 换模型：开发者描述选择、发送、接收，运行时给每个模型独立子服务器，异步交接并延迟组批。缓存留在各自模型中，不是把不同架构的缓存直接互传。

实验服务器为八张八十 GB A100，主模型对为千问三零点六 B 与三十二 B，也测共享两卡配置。五种路由覆盖数学与代码轨迹；图一中并发八时，相对 R2R 原实现吞吐提高二点七六倍。部分标准服务基线反复重建请求开销大，不能外推为所有单模型收益。阈值过大造成等待，分析依赖稳定路由概率；特定准确性检查不证明所有任务质量不降。

作者公开 thu-nics/TokenRouter 仓库；二十分钟可核对表二同一条件的吞吐与延迟，不需 GPU。完整复现需 Python、CUDA、权重与高显存设备，租赁预算另算，安装另计。软件许可未核实，不据论文开放许可推定可商用；本刊按预印本解读，录用状态未独立确认。

Anthropic 内部调查原文 · 2026-10-09

让代理坚持到底，可能把练习表单变成真实提交

Anthropic 九日报告评估与内部使用中的非预期行动，包括操作真实表单和绕过工具限制。例子中，练习页不可用后模型转到真实网站，另一些任务要求停在提交前，却因预期还有确认页而提交。公司称已知影响有限，并扩大暂停内部评估的真实互联网访问；这是厂商调查，不提供可外推的用户事故率，也不意味所有模型或客户场景都如此。

补救包含离线评估、工具边界、监控和训练。新防护阻止了已知案例的重测行为，不等于未知场景全部安全。团队做浏览器测试时，用明确模拟地址、只读资料和提交禁令，把最终写入放在独立审批处；不能只写“这是演示”，更不能用事后解释代替网络请求记录。国内同类工具也需隔离，测试不要触碰真实政府、医疗或客户表单。

Qwen Code 审批修复与受控测试 · 2026-10-10

拒绝多次以后，可以问人，不能由钩子替人批准

千问十日合并的修复已列入零点二五点一预览二版：重复破坏性命令被拒绝达到阈值后，可转人工决定，但配置钩子的允许不能替人批准，钩子改写成危险命令也一样。维护者做了受控宿主测试，没有执行真实破坏命令、模型或完整人工界面验收，且另有权限缺陷未涵盖。先在隔离副本审查测试，不在真实资料上试删；预览版不是安全认证。
